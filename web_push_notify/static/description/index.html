Web Push Notify

One reusable API for in-app popups and persistent Discuss inbox notifications.

Notifications that fit your workflow

  • Send to multiple active internal users in one call.
  • Choose popup, inbox, or both.
  • Configure popup duration or keep it visible until dismissed.
  • Open an authorized document directly from the notification.
  • Use plain text or sanitized HTML.

Built for custom addons

Private Python API, company-aware recipients, per-recipient document access checks, and transaction-bound delivery. A shared message has one inbox notification per recipient. No emails are queued.

users._push_notify(
    'Please review this document.',
    title='Review Required',
    duration=60000,
    popup=True,
    inbox=True,
)

Scope and requirements

Requires Odoo 17 with standard Web, Mail and Bus modules. Popups appear in a connected Odoo backend session. This is not browser/OS push and does not deliver popups while Odoo is closed. Inbox messages remain available after popup dismissal.

Developer integration is required. The caller controls business authorization and event deduplication. Supported actions open one existing document form. See the included README for the API and deployment requirements.
